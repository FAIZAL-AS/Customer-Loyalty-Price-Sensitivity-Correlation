# Customer-Loyalty-Price-Sensitivity-Correlation
A data analytics and machine learning project that analyzes customer loyalty and price sensitivity to help businesses understand purchasing behavior, segment customers, and make data-driven pricing and retention decisions.
## 📊 Data Requirements
To ensure the analysis works correctly, your uploaded CSV must contain the following **7 columns** exactly as named below:

| Column Name | Description |
| :--- | :--- |
| `customer_id` | Unique identifier for the customer |
| `price` | Price of the item purchased |
| `discount` | Discount amount applied |
| `total_spend` | Total amount spent by the customer |
| `purchase_count` | Number of times customer purchased |
| `basket_value` | Average value per transaction |
| `loyalty_flag` | Category of loyalty (e.g., High, Low) |

## 🚀 How to Run
1. Open your **CMD** (Terminal) in the project folder.
2. Run the app: `streamlit run app.py`
3. Example: `python -m streamlit run "C:\c programs\app.py"`
4.Note: Don't forget to include the full file path if you aren't already in the project folder.
